# Cotton Disease Model v1.0.0

## Overview
This is a crop-specific disease classification model for cotton.
- **Architecture**: efficientnet_b3
- **Input Size**: 300x300
- **Validation F1 Score**: 0.9926

## Classes
- Bacterial Blight
- Curl Virus
- Healthy Leaf
- Herbicide Growth Damage
- Leaf Hopper Jassids
- Leaf Redding
- Leaf Variegation
